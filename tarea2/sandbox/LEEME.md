# Carpeta autorizada para el servidor MCP

Esta es la única carpeta que puede ver el servidor de sistema de archivos de la Tarea 2.
El cliente lo lanza con esta ruta como argumento, y el servidor rechaza cualquier ruta
que quede fuera de ella, aunque el modelo la pida.

Contenido inicial:

- `proyecto/bitacora.md`: bitácora de la configuración del entorno.
- `proyecto/pendientes.md`: lista de pendientes; el modelo la modifica en la demostración.
- `notas/flutter-y-kmp.md`: apuntes sobre los dos repositorios de ejemplo.

Los archivos que el modelo cree durante la demostración también quedan aquí.
